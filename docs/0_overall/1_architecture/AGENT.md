- 测试真实入口可能揭示源码切片测试不可达的输入：`MyFileNameInput` 会把空格清洗为 `_`，因此空主名场景改测真实空值；PrimeVue 菜单应点击实际命令节点 `.p-contextmenu-item-content`。卸载后的事件用实际监听器观测，避免依赖不可靠的 `wrapper.emitted()`。
- 删除旧模块先核实生产调用、动态导入、生成清单与历史用途，再把有效契约映射到现行入口；不为保留旧测试而恢复已退出协议的计时器或状态。
- 模块是否拆分看职责、生命周期和复用价值；文件短或只有一个调用方不直接决定去留，也不因实现独立成文件就把它作为公共入口。
- 调整状态归属时核对 payload 键、序列化内容和初始化行为；有意改变时，按影响验证 SSR 与浏览器首次渲染的一致性。
- `block-beta` 试排能稳定表达局部左右并列，但总览的跨区直线仍穿过中间节点，固定网格未解决可读性。因此采用原主图加普通 flowchart 回调对照图；试排不支持把整个主图改成 `block-beta`。若需同时固定全部布局与折线路径，应考虑可手工布线的工具。
- 记录按批次区分实际新跑、沿用和未执行；静态导入图、历史测试及局部环境确认都有范围，不能扩大为当前整仓或生产验收。
