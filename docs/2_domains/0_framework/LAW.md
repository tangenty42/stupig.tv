# LAW：公共框架

- 本文档状态：DONE
- 覆盖范围：各页面共用的导航栏、页面加载、提示和确认、时间显示、自动更新、错误处理

## 导航栏

每个页面顶上都有：

- 最左边的蠢猪 Logo，点击回首页；
- Logo 下方的 breadcrumb，显示当前页面路径如 `蠢猪档案 / 详情 #42`；
- 右边的明暗模式切换按钮，以及登录注册入口；已登录则显示用户信息：自己的头像，hover 时弹出用户信息 hover card（卡片内容详见 `SID#2.1.LAW`）。

往下滚动时收起 Logo，只留面包屑和右侧按钮或用户信息。

浏览器标签页的标题默认跟随面包屑；档案详情、用户主页等页面会换成更具体的标题。

## 页面加载

- 打开网站时，页面准备好前会有遮罩、loading 转圈，遮住整个页面；
- 站内切换页面时，Logo 的位置会出现 loading 转圈。

## 提示和确认

- 操作成功、失败或有即时状态需要通知时，屏幕中间弹出 toast，几秒后自动消失；按 ESC 可以一次清掉所有 toast；
- 需要确认的操作，弹出对话框或在按钮旁边弹出小气泡，确认后才执行。

## 时间

- 页面上日期时间按访问者所在的时区显示；
- 日期时间显示应及时更新。

## 自动更新

对任何当前显示的页面，发生相关的数据更新（来自本页、其他页、其他设备、其他用户等等）时应立即引发渲染更新；若不便履行此机制——如果是『快照式』数据，如已强调是某个时间点的判断快照，则可例外，否则应至少采用轮询兜底。

## 错误处理

- 请求或操作失败时告知用户大概出了什么事（弹出提示，或在相应位置显示），不展示技术细节；
- 登录状态失效时自动退出登录。
