# LAW：引用

- 本文档状态：DONE
- 覆盖范围：档案 Markdown 中引用附件或其他档案的写法、改名跟随、存量引用确认机制

## 引用写法

| 链接写法 | 说明 |
| --- | --- |
| `att://路径` | 引用属于本档案的附件文件或文件夹 |
| `content://档案标题` | 引用其他档案 |

引用有删减版的机密附件的链接，相当于同时引用该机密附件本身及其删减版。

## 改名跟随

- 附件文件或文件夹改名（或移动），或者其他某个档案更名后，本档案的正式版和云端草稿里对它的引用链接会自动改成新的；
- 更名会留下记录，称『引用历史』，以便跨端、延时同步等。

## 存量引用确认

删除附件或档案之前，弹出存量引用确认 dialog，检查有没有相关内容还在引用它，有则列举提示，二次确认后方可删除。
