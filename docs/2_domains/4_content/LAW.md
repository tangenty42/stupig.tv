# LAW：蠢猪档案

- 本文档状态：DONE
- 覆盖范围：蠢猪档案的相关概念及总规则

## 概念

| 说法 | 含义 |
| --- | --- |
| 档案 | 一篇文章，包含摘要、正文和附件 |
| 档案 Markdown | 通过 Markdown 表达档案的摘要和正文，为档案存储和编辑的主要形式 |
| 摘要 | 档案的标题、标签、说明、封面、事件日期，出现在档案卡片上，详见 `SID#2.4.0.LAW` |
| 正文 | 档案 Markdown 里摘要以外的部分，是文章的主体内容 |
| 附件 | 挂在某篇档案下的文件，可放进文件夹 |
| 正式版 | 某篇档案已发布的最新版 Markdown |
| 草稿 | 某篇档案还没发布的 Markdown；新档案在第一次发布前也只是草稿 |
| 机密内容 | 正文里被标为机密的 Markdown 内容，或被标为机密的附件 |
| 删减版 | 机密附件的公开版本 |

## 身份与权限

| 身份或权限 | 能做什么 |
| --- | --- |
| 访客、用户 | 看档案列表（档案卡片中含摘要），读正文里非机密的部分，打开、下载非机密附件，查看机密附件的删减版 |
| 『蠢猪档案·机密可读』权限 | 能做访客、用户能做的，另：能看机密内容（包括机密 Markdown 内容及机密附件） |
| 『蠢猪档案·完全』权限 | 能做『机密可读』能做的，另：能新建、编辑、发布、删除档案（及草稿），及管理附件 |
