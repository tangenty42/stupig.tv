# LAW：档案 Markdown

- 本文档状态：DONE
- 覆盖范围：档案 Markdown 格式、方言语法

## 档案 Markdown

覆盖档案摘要及正文内容。

<!-- eslint-skip -->
```markdown
---
title: 高三下学期
label: #置顶 #拉完了 必看
time: 2026/1 ~ 2026/6
desc: 草草草草草
cover: ![苦中作乐这一块](att://痛苦面具.jpg)
---

<!-- 以上为填写摘要的 front matter，必须从第一行开始 -->
<!-- title 标题：唯一必填，需为纯文本 -->
<!-- label 标签：每个标签以空格分隔 -->
<!-- time 事件日期：支持时间点或时间段，日期格式支持 年/月、或 年/月/日；注意，如果是时间段，则起、止日期都应采用相同的日期格式（要么都是 年/月，要么都是 年/月/日）；省略表示无确切时间 -->
<!-- desc 说明：需为纯文本 -->
<!-- cover 封面：![图片 alt 文本，可为空](图片链接) -->

front matter 之后即是正文。

开始秀特殊语法——

## 附件卡片

[](att://附件文件路径)
[](att://附件文件夹路径)
<!-- 注意 [] 里不能填任何东西，否则渲染为一般的链接条 -->

- 会自动渲染成附件卡片，显示附件 icon、名称、大小（文件夹为直属 item 个数）等信息；
- 点击打开或下载对应附件（文件夹为跳转到附件列表对应位置）；
- 有权查看的机密附件会有特殊样式；
- 若是无权查看的机密附件（且无删减版），直接显示统一的『无权查看』占位；
- 路径无效也会显示统一的『渲染失败』占位。

## 档案卡片

[](content://档案标题)
<!-- 注意 [] 里不能填任何东西，否则渲染为一般的链接条 -->

- 会自动渲染成档案卡片，显示档案摘要；
- 点击跳转对应档案；
- 档案标题无效会显示统一的『渲染失败』占位。

## 图片卡片

![图片 caption，可为空](任何图片链接，可为外部图片，也可为 att:// 开头的附件图片)

- 图片 caption 显示为图片下方的一个 section；
- 点击图片可预览对应图片；
- 若是有权查看的图片类型的机密附件，会有特殊样式；
- 图片无效会显示统一的『渲染失败』占位。

## Carousel

<carousel>
<!-- 任意内容 -->
</carousel>

将其中所有内容渲染在可横向滚动的 Carousel 中——超出屏幕时带有提示，提示用户可横向滚动。

## 内嵌 iframe（仅限 B 站视频）

![标题，可为空](iframe://player.bilibili.com/player.html?blablabla)

可内嵌 B 站视频——在 B 站点击 分享 → 嵌入代码 得到的播放器链接，把协议头改成 `iframe://` 填入链接即可。

## Github 风格提示框

> [!TYPE] 标题
>
> 内容
<!-- TYPE 可为：NOTE / TIP / IMPORTANT / WARNING / CAUTION -->
<!-- 标题可要可不要，不要则根据 TYPE 渲染默认值，如 NOTE 对应 提示 -->

## 正文里的机密内容

<good>这是一段机密内容</good>

解析器会解析 <good></good> 标签内所有内容为机密正文内容。对无权查看之人显示『无权查看』占位。
```
