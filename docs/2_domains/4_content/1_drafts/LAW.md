# LAW：草稿机制

- 本文档状态：DONE
- 覆盖范围：云端草稿、编辑权、自动保存、发布、舍弃草稿、删除档案、未发布草稿列表

## 云端草稿

- 每篇档案最多有一份云端草稿，只存 Markdown（摘要 + 正文）不存附件（附件为草稿和正式版共用），供所有编辑者共用；
- 编辑档案时，档案内容自动保存进云端草稿；读者看到的仍是已发布的版本，直到点『保存』才发布；
- 新建档案时先得到一份未发布的草稿，首次『创建』后才正式发布；
- 新档案第一次发布后才能上传附件；
- 图片编辑器打开时，按 Ctrl+S（macOS 为 ⌘S）等同于点击图片编辑器的『保存』；图片编辑器关闭时，在档案编辑页按同一快捷键等同于点击『保存』或『创建』。

## 编辑权

- 同一时间只有一个页面能编辑一份草稿；别的页面打开时只能看，显示『其他页面正在编辑』；
- 编辑页切到后台、关闭或断线时，自动保存并让出编辑权；回到前台时再尝试取得；
- 离开时有未确认保存至云端的修改时——
  - 站内跳转：跳转前先尝试保存云端草稿，草稿保存失败或超时再弹 dialog 让选择留下或离开；
  - 刷新或关闭标签页时：触发浏览器原生的离开提醒（如 `离开网站？您所做的更改可能未保存`）。
- 如果编辑权被别处拿走，本页还没上传的内容放进『恢复区』并弹 dialog 显示，可以当即复制保留——关闭恢复区 dialog 后该内容被抛弃。

## 舍弃与删除

- **舍弃草稿**：若档案已发布，则可丢弃已有草稿内容、并将其同步为云端已发布的版本；若档案还从来没有发布过，则整份草稿直接删除；
- **删除档案**：档案 Markdown（包括草稿）和所有附件一起删除；删除前显示有哪些其他档案引用了它（若有），确认后才能删。

## 未发布草稿列表

在档案列表页切到『未发布草稿』，能看到从没发布过的草稿和有未发布修改的草稿，点进去跳转编辑。
