# LAW：存储与后台任务

- 本文档状态：DONE
- 覆盖范围：附件存储方式与后台任务

## 存储

所有附件储存在私有读的阿里云 OSS 存储桶，由 ESA 提供鉴权及公共访问；机密附件并没有加密，是否机密只影响鉴权结果。

OSS 存储桶设置保留每个文件的历史版本 7 天。

## 后台任务

| 任务 | 职责 | 停摆代价 |
| --- | --- | --- |
| 图片处理 | 把上传的图片处理成 WebP、JPEG 和 LQIP，见 `SID#2.4.5` | 档案新图片无法正常渲染 |
| 上传收尾 | 清理过期、放弃的上传 | 过期的上传碎片占用存储空间 |
| 对象退役 | 物理删除待删文件、清理 CDN 缓存 | 逻辑删除删掉的文件仍留在存储里 |
| 边缘预热 | 把显示版和兼容性 fallback 版推到 CDN 以预热缓存 | 首次加载图片慢一点 |
| 回执压缩 | 清理过期的操作回执 | 回执表过大 |
| 存储审计 | 扫描缺失、大小不符、ACL 不正确、引用无效、已删仍在、疑似无主、不受管理的文件，以及没登记的站点静态图片（存放在对象存储中的静态图片，须通过配置系统，按完整对象键登记） | 发现不了一些神秘问题 |
