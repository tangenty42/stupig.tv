# LAW：档案摘要、列表与详情页

- 本文档状态：DONE
- 覆盖范围：档案摘要的组成、档案列表页、档案详情页、事件日历

## 摘要

| 摘要 | 是否必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 唯一，不能重名 |
| 事件日期 | 否 | 某一天、某个月，或一段时间；不填，则默认为『无确切时间』（在按时间排序时表现为——比所有『确切时间』更靠近未来） |
| 标签 | 否 | 可自定义，显示在档案卡片和详情页上，可用来筛选；另有两种特殊标签，见下 |
| 说明 | 否 | 标题下的一段纯文字 |
| 封面 | 否 | 封面图，最多一张；不能为机密附件 |

两种特殊标签：

- **评分**：从低到高分五档（拉完了、NPC、人上人、顶级、夯），以水印显示在卡片上；缺省此类标签的归为『难评』；
- **置顶**：让档案排在列表最前面，可以不止一个。

## 档案列表页

- 显示档案总数和全部档案的卡片，卡片放置封面图、标题、说明、标签和事件日期，还有评分水印——部分视条件决定是否显示；
- 默认按事件日期从新到旧排，也可以改为按评分从高到低排；置顶的总在最前；
- 可点选标签筛选，选了多个时显示带有其中任一标签的档案；
- 页面最下方是事件日历（见下）；
- 若有『蠢猪档案·完全』权限，还能新建档案、切换显示『未发布草稿列表』。

## 档案详情页

- 依次放置摘要（及评分水印）、正文、事件日历、附件——部分视条件决定是否显示；
- 事件日历默认翻到这篇档案的事件月份，并突出当前此篇；
- 有『蠢猪档案·完全』权限的人能从此页进入编辑；
- 档案不存在或已删除时，显示『档案不存在或已被删除』。

## 事件日历

- 按月显示；每篇事件日期为『确切时间』的档案，按其时间跨度，以一条条不同颜色的条展示在日历上，点击即跳转到该档案；
- 只能翻到有档案的月份范围；列表页的日历默认显示最晚一篇档案的月份；详情页的日历只能在这篇档案的事件月份之间翻。
