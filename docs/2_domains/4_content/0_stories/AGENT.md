## 其他出入

1. **`list_stories` 的排序没有被用上。** 服务端按 `updated_at` 倒序返回，列表页在前端按置顶、事件日期重新排序，日历也自己排序。服务端的排序只决定其他使用者拿到的顺序，不影响页面。
2. **日期排序用的是拼接后的字符串。** `event_dates.join(',')` 的字典序在日期格式统一时等于按最早日期排序，再按后续日期比较。如果将来日期格式变化（比如没有补零），排序会出错。目前写入时已排序并统一格式，所以没有实际问题。
