## 落实与验证

2026-11-24 大图预览加载时将 LQIP 限在暗色遮罩中央并等比显示。用实际组件与编译样式在独立 Chromium 中核对了 1280 px 和 390 px 窗口，原图加载后占位与转圈都结束。生产样式回归用例已补充，整套夹具因本地 MySQL 连接受限未启动。

2026-11-24 后续将大图加载画面改为只转圈，失败由当前请求决定。独立 Chromium 核对了延迟返回 404、关闭后重开同一地址并成功加载的全过程。封面按尺寸预留，同一渲染产物与编译样式在现代 Chromium 和 Chromium 80 校验了 24 种加载前后尺寸。正文与封面共用加载状态，头像失败时保留首字母回退，头像 URL 变化时重新加载。191 项定向单测和 61 项组件测试通过。生产样式用例已更新，运行时本地 MySQL 连接受限。

2026-11-24 正文、封面和大图的加载状态改用 450 毫秒交叉淡化，无尺寸提示时同步过渡占位框大小。独立现代 Chromium 验证了有和无 LQIP 的过渡、无尺寸封面和正文的成功及失败、大图淡入期间关闭和减少动态效果。Chromium 80 确认无尺寸图可加载，测试所用的动画枚举 API 不可用，中点测量未完成。139 项定向单测、20 项组件测试、lint 和类型检查通过。应用 E2E 在连接本地 MySQL 时收到 `EACCES`。

2026-11-24 清晰图开始淡入时冻结 LQIP 的呼吸相位，由清晰图逐渐覆盖，消除双重透明度变化造成的闪底。现代 Chromium 在明暗主题逐像素复现并验证了改善，已把取样检查加到图片加载 E2E。lint 和 E2E 类型检查通过。应用 E2E 仍在连接本地 MySQL 时收到 `EACCES`。

2026-11-24 清晰图改用 1.4 秒缓入缓出渐显，缓存命中也从占位帧渐显。独立 Chromium 核对了正文、封面、大图、占位尺寸和减少动态效果。225 毫秒时清晰图约显出 5%，700 毫秒时显出一半。142 项定向单测和 21 项组件测试通过。应用 E2E 在连接本地 MySQL 时收到 `EACCES`。

2026-11-24 有低清图时等当前呼吸自然结束，再用同一段 1.4 秒过渡完成低清图淡出和清晰图渐显。独立 Chromium 核对了加载完成与呼吸周期末尾的事件顺序，以及明暗主题下的同色、异色和透明图取样。174 项定向单测、21 项组件测试、lint 和类型检查通过。应用 E2E 在连接本地 MySQL 时收到 `EACCES`。
