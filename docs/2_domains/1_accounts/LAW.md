# LAW：账号与权限

- 本文档状态：DONE
- 覆盖范围：注册、登录、退出登录、验证码、个人主页、资料与安全、登录记录、权限、账号状态

## 概念

| 概念 | 定义 |
| --- | --- |
| 访客 | 没登录的人 |
| 用户 | 已登录的人 |
| 大手发力 | 有『控制台』系列权限的人（如管理员）可直接查看（若有权限，还可编辑）他人的账号信息 |

## 成为蠢猪

访客点击右上角『登录 / 注册』打开弹窗。

注册须填用户名（2 ~ 32 字符，全站唯一）、手机号（全站唯一）、密码（8 ~ 64 位，不允许纯数字或出现连续 4 位重复或有规律字符）、再输入密码，以及发送、填写手机验证码。注册成功：『欢迎新生小猪~』并自动登入。

新账号默认不带任何『权限』（也不是管理员），详见下文。

## 登录与退出

可通过用户名（或手机号）+ 密码，或者手机号 + 手机验证码登录。

用户可通过触发右上角用户信息的 hover card，点击其上的『退出登录』来退出。

有以下几种情况会触发强制退出：账号被封禁、账号或设备被强制下线 / 退出、或登录状态过期。

## 手机验证码

发送手机验证码的按钮在可发送时显示『发送』，否则显示冷却倒计时。

冷却策略分不同阶段，一开始冷却时间短，达到阈值之后变长；发送次数每日有上限。

同一手机号或同一设备被视为同一主体，共享同一套冷却及限额状态。

## 个人主页

用户可通过触发右上角用户信息的 hover card，点击其上的『我的主页』来进入自己的个人主页。

无论是访客还是用户，都可访问任何人的个人主页，但相比看自己的主页，敏感信息以及修改信息的按钮会隐藏。

通过『大手发力』，可像访问自己的主页一样访问任何人的个人主页，可以随便读写。

### 个人资料

这里只列举用户可在自己主页更改的资料。

| 资料 | 可进行操作 | 可由谁操作 |
| --- | --- | --- |
| 生日 | 修改或清空 | 用户本人或『大手发力』 |
| 头像 | 选择新头像、裁剪并上传，替换旧的；也可删除当前头像回归默认 | 用户本人或『大手发力』 |
| 改密码 | 输入旧密码或验证手机号、验证是本人后可修改密码 | 用户本人或『大手发力』（其中『大手发力』无需验证步骤） |
| 换手机号 | 验证旧手机号、新手机号后可更换绑定的手机号 | 用户本人或『大手发力』（其中『大手发力』无需验证步骤） |

### 登录记录

用户可查看登录过自己账号的设备信息、并强制下线特定设备（当前设备除外）。

## 权限

| 权限分类 | 权限级别 | 能干什么 |
| --- | --- | --- |
| 控制台 | 只读 | 进控制台，看用户列表 |
| 控制台 | 完全 | 在控制台里管理用户，发动『大手发力』；管理员特有，不能赋予普通用户 |
| 蠢猪档案 | 机密可读 | 看档案里的机密内容和机密附件 |
| 蠢猪档案 | 完全 | 新建、编辑、删除档案及其附件 |

一般把权限分类及其级别放在一起说，如『蠢猪档案·完全』权限。

管理员拥有所有这些权限。可给默认无权的普通用户逐条赋予权限（『控制台·完全』除外）。

『蠢猪档案』相关权限详见 `SID#2.4.LAW`。

## 账号标记

| 标记 | 说明 |
| --- | --- |
| 认证 | 用户名旁边带认证标识、个人主页展示认证说明 |
| 封禁 | 无法登录、无法进行任何需要账号的操作、立即退出登录 |
| 管理员 | 拥有所有权限，至高无上 |
