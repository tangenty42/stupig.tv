# LAW：管理控制台

- 本文档状态：DONE
- 覆盖范围：控制台入口、用户列表、用户管理操作、后台任务、存储审计

## 入口

右上角用户信息的 hover card 对有权限之人显示『控制台』按钮，点击进入。

进入后默认显示『用户』分页，可切换到『运行状态』分页。

## 用户列表

分页展示实时的全站用户及其信息（卡片），卡片上有一堆操作按钮。

## 管理操作

需要权限：『控制台·完全』。

| 操作 | 说明 |
| --- | --- |
| 封禁 / 解封 | 效果见 `SID#2.1.LAW` 的『账号标记』；不能封禁自己 |
| 强制下线 | 让该用户在所有设备上退出登录 |
| 授予 / 修改 / 移除认证 | 授予时填写认证说明 |
| 设为 / 撤销管理员 | 不能撤销自己的管理员 |
| 修改权限 | 给非管理员用户逐条授予或收回权限；不能为普通用户单独授予『控制台·完全』 |
| 编辑 | 打开该用户的个人主页，发动『大手发力』（详见 `SID#2.1.LAW`） |

## 运行状态

需要权限：『控制台·只读』。

只读查看全部后台任务，包括各项任务的待办数量、运行状况，以及出错或停用的情况。
